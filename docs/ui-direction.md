# TenderScope UI Direction

TenderScope uses an editorial intelligence-system aesthetic rather than a generic dashboard template.

- Oversized display typography and compact data typography
- Near-black mineral backgrounds with warm paper surfaces
- Structured asymmetry, generous negative space and deliberate visual tension
- Motion limited to information hierarchy, hover depth and progressive disclosure
- High-contrast controls, visible focus states and reduced-motion support
- No decorative 3D, stock dashboard gradients or excessive glassmorphism
